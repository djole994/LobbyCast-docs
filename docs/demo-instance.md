# Demo Instance

All screenshots in this repository come from a **separate demo instance** of LobbyCast. The production system and its data are never used for presentations.

---

## 1. Fictional Organisation

| Setting | Demo value |
|---|---|
| Organisation name | Northfield University |
| Logo | Fictional emblem (see [northfield-logo.svg](../examples/custom-slides/demo-kit/northfield-logo.svg)) |
| Screens | TV1 – Main lobby, TV2 – Library entrance, TV3 – East wing |

Everything shown in the demo is invented: the organisation, people, rooms, classes, exams and events. Any similarity to real people or institutions is coincidental.

---

## 2. Demo Content

---

## 3. What Is Hidden

Before publishing, the screenshots were checked and the following was removed or blurred:

- the public address of the instance
- usernames
- any institutional names, logos and data
